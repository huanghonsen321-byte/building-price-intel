# 广东省公共资源交易平台 - 关键词覆盖报告

## 扫描时间
2026-05-19

## 扫描目标
判断广东省公共资源交易平台数据少是关键词问题还是平台本身数据有限。

## 扫描结论

**核心结论：广东平台是工程招投标源，不适合做脚手架/周转材料数据的主力源。**

- 脚手架 = 27 条（平台定位是工程招投标，非材料采购）
- 盘扣式脚手架 = 18 条
- "盘扣" = 320 条（绝大多数为"盘岭"地名假阳性）

### 高噪音关键词（需排除或降级）

| 关键词 | 命中数 | 问题 |
|--------|--------|------|
| 盘扣 | 320 | "盘岭"地名假阳性（319/320条） |
| 工程材料 | 206,601 | 过于宽泛，几乎覆盖所有工程类 |
| 模板工程 | 221,318 | 过于宽泛，非脚手架相关 |

### 排除关键词（需负向过滤）

以下关键词命中过多或假阳性极高，建议仅用于离线发现：
- 盘扣（320，98%为"盘岭"）
- 工程材料（206,601，过宽）
- 模板工程（221,318，过宽）
- 建筑材料（预期极高，过宽）
- 租赁（预期极高，过宽）

## 策略调整

### 原关键词列表（已替换）
```python
GUANGDONG_KEYWORDS = [
    "脚手架", "盘扣", "钢管", "钢管扣件租赁",
    "周转材料租赁", "模板脚手架",
]
```

### 新两层关键词列表

第一层：core 精确关键词，可直接进入生产 plan。

```python
CORE_KEYWORDS = [
    "脚手架", "盘扣式脚手架", "扣件式脚手架", "钢管脚手架",
    "模板脚手架", "脚手架搭拆", "钢管扣件租赁", "周转材料租赁",
    "附着式升降脚手架", "盘扣架租赁", "钢管租赁", "扣件租赁",
]
```

第二层：discovery 探索关键词，只用于补充搜索，命中结果必须经过负向词和上下文二次过滤后才能入库。

```python
DISCOVERY_KEYWORDS = [
    "钢管", "盘扣", "扣件", "模板", "支架", "周转材料",
    "安全网", "顶托", "钢跳板", "铝模", "木方",
]
```

主要变化：
- 不把 "盘扣" 作为 core（假阳性率 98%+），但保留为 discovery，必须二次过滤。
- 恢复 "钢管" 为 discovery，因为历史真实 run 证明它能带来广东省公共资源交易平台真实命中。
- 新增 "盘扣式脚手架"、"扣件式脚手架"、"附着式升降脚手架" 等精确 core。
- 对 discovery 结果要求至少包含一个上下文词：脚手架、租赁、支撑、钢管、扣件、模板、周转材料、架体、搭拆、工程、采购、招标、中标、施工。

### 数据源定位调整
- **原定位**：省级主力源
- **新定位**：低频辅助源（周更）
- **理由**：平台主要发布工程招投标信息，脚手架/周转材料仅作为附带内容出现

## 后续建议

### 更合适的数据源
1. **中国政府采购网** (ccgp.gov.cn) — 材料采购招标
2. **各地市政府采购网** — 更细粒度的材料采购
3. **建筑行业垂直平台**：
   - 我的钢铁网 (mysteel.cn) — 钢材/钢管价格
   - 筑材网 — 建筑材料采购
4. **供应商授权API** — 盘扣脚手架厂商/经销商的直采API

### 广东平台使用建议
- 作为补充数据源，不期望大量脚手架数据
- 周更而非日更
- 结合负向过滤和上下文匹配
